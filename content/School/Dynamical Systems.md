### For all Symbol ∀
The ∀ (for all) symbol is used in math to describe a variable in an expression. Typically, the symbol is used in an expression like this:

$$∀x∈R$$

In plain language, this expression means for all x in the set of real numbers. Then, this expression is usually followed by another statement that should be able to be proven true or false. [Read more…](https://wumbo.net/notation/for-all/ "For All")
