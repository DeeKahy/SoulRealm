rust automatic datatype detection (i32):
```rust
let x = -7 / 5;
let y = -7 % 5;

println!("{x}"); // = -1
println!("{y}"); // = -2
```


Rust f32
```rust
let x = -7. / 5.;
let y = -7. % 5.;

println!("{x}"); // = -1.4
println!("{y}"); // = -2

```
