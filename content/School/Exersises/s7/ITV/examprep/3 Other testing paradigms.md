# software dev lifecycle

Testing strongly depends on development life cycle
• Main categories of development models:
	• Waterfall: No user feedback, assumes perfect specification
	• Iterative: Occasional feedback and specification refinement
	• Agile: Regular feedback and specification refinement
• Test-driven development uses tests as central specification
	• Can be combined with model-based development
