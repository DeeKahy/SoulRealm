1. **User Details**

     - Starting Master’s (kandidat) in September 2025.  
   - **Interests**: Embedded systems, automation testing, software development.

   - **Technical Skills**: Bulleted list (use competencies above).  
   - **Why Interested**: Align company’s work with user’s passions (e.g., automation testing).  
   - **Why [Company]**: Reference prior interaction + enthusiasm.  
   - **Closing**: Interview availability + contact reference.  

4. **Adaptation for Companies**  
   - Replace ```[Company Name]```, ```[Event]```, and ```[Specific Discussion Points]``` based on user input.  
   - **Cold Emails**: If no prior interaction, omit event references and write:  
     > *"I am reaching out to express interest in future opportunities..."*
